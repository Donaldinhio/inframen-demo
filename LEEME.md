# INFRAMEN · Demostración para GitHub Pages

Esta es una copia independiente para explorar la interfaz. No necesita Node.js, MySQL ni Railway.
Todos los nombres y movimientos incluidos son ficticios. No se realizan solicitudes a una API ni se guardan datos en cookies, localStorage o sessionStorage. La sesión solo existe en memoria y se cierra al recargar.

## Publicar
1. Descomprime este ZIP.
2. Crea un repositorio en GitHub y sube el contenido de esta carpeta: index.html debe quedar en la raíz, junto a assets. No subas el ZIP sin descomprimir.
3. Abre Settings > Pages > Deploy from a branch.
4. Selecciona main y /(root), luego Save.
5. Espera a que GitHub publique y muestre el enlace.

## Qué se puede explorar
Inicio de sesión por rol, resumen, cobros, catálogo, pedidos, comprobantes en pantalla, paneles administrativos, filtros, formularios y búsqueda de entregas (folio CMP-DEMO-0002).

Los formularios de registro, compras, pagos, entregas, edición y eliminación solo se muestran: al confirmar aparece un aviso y no se modifica ningún registro. Las descargas PDF/Excel/CSV y evidencias del servidor muestran un aviso de función no disponible en esta demo.

Para probar localmente puedes abrir index.html con doble clic o usar un servidor estático. Esta copia no sustituye el proyecto original con Node.js y MySQL.
